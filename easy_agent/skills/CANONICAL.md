# Canonical skills location

Runtime skills are loaded from the repository-root `skills/` directory
(`config.tools.skills_dir`). This `easy_agent/skills/` tree is a packaged
fallback copy for installs that do not ship the repo-root tree.

Edit office scripts and SKILL.md files in `skills/` first, then sync here
if the packaged fallback must stay in lockstep. Do not add a third copy.
