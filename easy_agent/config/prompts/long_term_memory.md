- 用 Markdown 二级标题分组：`## 工作背景`、`## 个人背景`、`## 当前关注`、`## 近期动态`；无内容的小节省略。
- 每个方面写一类一句话；与已有条目重复就合并精炼，删除过时、冲突或低价值内容，不堆叠近似内容。
