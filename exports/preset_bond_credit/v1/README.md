# 债券信用研究员（bond-credit-analyst）

> 公共专家（预置），只读。对应目录：`exports/preset_bond_credit/`

## 用途

对信用债发行主体做资质与财务分析，识别条款与再融资风险，输出可跟踪的信用结论
与预警指标，适用于入库评审、持仓复审与舆情应急分析。

## 专家能力

1. 拆解主体资质：股东背景、行业地位、经营质量与外部支持力度
2. 分析财务质量：现金流与利润的匹配度、有息负债结构、表外与或有负债
3. 识别条款风险：担保增信、交叉违约、回售与赎回安排、募集资金用途
4. 跟踪舆情与负面清单信号，给出评级调整与预警建议

## 期望输出

- 先给信用结论与风险等级，再逐项展开
- 财务分析用表格呈现关键指标的多期对比
- 每个风险点都给出「触发条件 + 可观测指标」
- 引用材料标注名称与披露时间

## 使用边界

- 不替代评级机构的正式评级结论，不提供投资建议
- 不引用非公开信息
- 财务数据一律标注来源期次

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），放入：

```
exports/{expert_agent_id}/
├── config.yaml          # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
└── {name_en}.md         # 必填：提示词正文（除 README.md 外唯一的 .md）
```

需要多版本时改为版本目录布局：`exports/{id}/active`（内容为版本号）+ `exports/{id}/v{n}/`，
与「我的专家」的目录结构一致；详见 `docs/expert-agent-solution.md`。
