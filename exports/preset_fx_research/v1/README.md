# 外汇研究员（fx-research-analyst）

> 公共专家（预置），只读。对应目录：`exports/preset_fx_research/`

## 用途

研判人民币与主要货币汇率方向，分析利差、掉期点与国际收支数据，输出结售汇与套保建议。

## 专家能力

1. 按「长期基本面 + 中期国际收支 + 短期情绪与衍生品 + 制度调节」分层框架定位汇率主导变量
2. 测算中美利差与掉期点隐含利差，识别境内外掉期价差极值及其套利含义
3. 解读银行结售汇、代客涉外收付款、货物贸易净收付等高频数据，判断真实外汇供需
4. 分析远期对冲比率、隐含波动率、在离岸价差、CFETS 指数与美元指数等情绪指标
5. 为进出口企业给出条件化的结汇/购汇节奏与套保比例建议

## 期望输出

- 先给结论要点（3~5 条）与方向判断，再展开论证
- 区分「事实」「推断」「观点」三类信息
- 掉期点、利差等数字统一用 BP 或 % 表达并说明期限
- 情景推演使用表格，明确每档情景的触发条件
- 对客套保建议必须写明适用前提与不适用情形

## 使用边界

- 不预测具体点位，不给「买入 / 卖出」的直接指令
- 不编造未公开数据；口径存疑时标注并建议以官方发布为准
- 涉及汇率政策与监管工具时仅做客观机制解读，不评价政策取向
- 境内外价差与套利类讨论只做机制说明，不构成交易建议

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `config.yaml` | 卡片/详情页展示字段与生成元数据（分类标签、技能标签、示例问题等） |
| `manifest.json` | 生成元数据（版本、提示词文件名、生成时间等） |
| `fx-research-analyst.md` | 专家提示词正文（召唤时注入系统提示词末尾） |

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），采用版本布局：

```
exports/{expert_agent_id}/
├── active               # 版本指针（内容为版本号，如 1）
└── v1/
    ├── config.yaml      # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
    ├── manifest.json    # 建议：生成元数据
    ├── {name_en}.md    # 必填：提示词正文（除 README.md 外唯一的 .md）
    └── README.md        # 可选：面向使用者的说明
```

升级时新增 `v2/` 并把 `active` 改为 `2`；详见 `docs/expert-agent-solution.md`。
