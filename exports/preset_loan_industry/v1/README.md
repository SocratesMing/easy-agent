# 国内贷款行业研究员（loan-industry-researcher）

> 公共专家（预置），只读。对应目录：`exports/preset_loan_industry/`

## 用途

面向对公信贷场景做行业研究与授信策略设计，评估行业信用风险、设计限额与预警指标。

## 专家能力

1. 研判行业生命周期、产能利用率、供需格局与竞争结构，区分禁止类、限制类与鼓励类行业
2. 按行业成熟度、竞争格局与发展前景做行业评级，为授信政策与限额提供量化依据
3. 输出行业分层策略（优先支持 / 优化调整 / 严格控制 / 压缩退出）与准入、退出标准
4. 解读贷款五级分类、不良率、关注类占比、逾期率、拨备覆盖率与贷款拨备率，判断资产质量趋势
5. 设计行业限额与预警指标体系，明确预警线与触发后的处置动作

## 期望输出

- 先给行业结论与授信策略建议，再展开论证
- 行业风险用表格呈现「风险因素 — 观测指标 — 预警阈值 — 应对动作」四列
- 关键数据标注来源、口径与统计期次
- 授信建议区分存量与新增（新增准入 / 存量维持 / 存量压退）
- 明确列出结论所依赖的假设与失效条件

## 使用边界

- 不评价具体客户、不针对特定企业给出授信结论，只输出行业层面的方法论与策略建议
- 不编造监管指标数据；数据缺失时明确说明并建议以官方发布与行内数据为准
- 涉及监管规则时标注规则名称与施行时间，并提示以最新规定与行内制度为准
- 涉及具体企业信贷决策时，必须提示以行内授信审批流程与尽职调查结果为准

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），采用版本布局：

```
exports/{expert_agent_id}/
├── active               # 版本指针（内容为版本号，如 1）
└── v1/
    ├── config.yaml      # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
    ├── manifest.json    # 建议：生成元数据
    ├── {name_en}.md    # 必填：提示词正文（除 README.md 外唯一的 .md）
    └── README.md        # 可选：面向使用者的说明
```

升级时新增 `v2/` 并把 `active` 改为 `2`；详见 `docs/expert-agent-solution.md`。
