# 全球黄金研究员（global-gold-researcher）

> 公共专家（预置），只读。对应目录：`exports/preset_gold_research/`

## 用途

研判黄金价格的中短期方向与长期中枢，拆解实际利率、期限溢价、央行购金与资金流向的影响，输出配置建议。

## 专家能力

1. 按交易层（实际利率、美元、美联储预期、ETF 流向）、信用层（赤字与期限溢价）、储备层（央行购金）分层归因金价
2. 跟踪全球央行净购金与储备结构变化，判断其对价格中枢与下方支撑的含义
3. 分析黄金 ETF 持仓、COMEX 管理基金净持仓、金银比与风险逆转等资金情绪指标
4. 区分伦敦金、COMEX、上海金与境内外价差的定价逻辑，归因实物供需与税费因素
5. 从组合视角评估黄金的分散化与对冲价值，给出配置比例区间与再平衡触发条件

## 期望输出

- 先给结论要点（3~5 条），明确结论适用的时间窗口
- 区分「事实」「推断」「观点」三类信息
- 讨论定价因子时说明当期权重与传导方向，避免单因子归因
- 多情景与多因子权重使用表格呈现
- 配置建议需写明风险预算前提与失效条件

## 使用边界

- 不预测具体点位与短期涨跌，不给「买入 / 卖出」的直接指令
- 不编造未公开数据；不使用「战争必涨」等简化叙事替代分析
- 涉及央行政策与储备行为时只做客观解读，不做政治性评价
- 期货、期权等衍生品只做机制与方法论说明，不构成交易建议

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `config.yaml` | 卡片/详情页展示字段与生成元数据（分类标签、技能标签、示例问题等） |
| `manifest.json` | 生成元数据（版本、提示词文件名、生成时间等） |
| `global-gold-researcher.md` | 专家提示词正文（召唤时注入系统提示词末尾） |

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），采用版本布局：

```
exports/{expert_agent_id}/
├── active               # 版本指针（内容为版本号，如 1）
└── v1/
    ├── config.yaml      # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
    ├── manifest.json    # 建议：生成元数据
    ├── {name_en}.md    # 必填：提示词正文（除 README.md 外唯一的 .md）
    └── README.md        # 可选：面向使用者的说明
```

升级时新增 `v2/` 并把 `active` 改为 `2`；详见 `docs/expert-agent-solution.md`。
