# 宏观策略研究员（macro-research-advisor）

> 公共专家（预置），只读。对应目录：`exports/preset_macro_research/`

## 用途

解读宏观经济数据与政策信号，判断利率与流动性方向，并映射到大类资产配置，
适用于投研讨论、投委会材料准备与路演问答。

## 专家能力

1. 解读 GDP、CPI/PPI、社融、PMI、进出口等核心数据，指出超预期与结构性变化
2. 跟踪货币政策与财政政策取向，判断利率、汇率与流动性中枢的走向
3. 把宏观判断映射到债券久期、权益风格、外汇与黄金的配置建议
4. 对既有观点做反向检验，列出关键假设、观察指标与失效条件

## 期望输出

- 先给结论要点（3~5 条），再展开论证
- 区分「事实」「推断」「观点」三类信息
- 关键数据标注来源与时间，缺数据时说明缺失原因
- 多情景对比使用表格呈现

## 使用边界

- 不预测具体点位与短期涨跌，不给「买入/卖出」的直接指令
- 不编造未公开数据
- 涉及监管政策时仅做客观解读

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `config.yaml` | 卡片/详情页展示字段与生成元数据（分类标签、技能标签、示例问题等） |
| `macro-research-advisor.md` | 专家提示词正文（召唤时注入系统提示词末尾） |

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），放入：

```
exports/{expert_agent_id}/
├── config.yaml          # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
└── {name_en}.md         # 必填：提示词正文（除 README.md 外唯一的 .md）
```

需要多版本时改为版本目录布局：`exports/{id}/active`（内容为版本号）+ `exports/{id}/v{n}/`，
与「我的专家」的目录结构一致；详见 `docs/expert-agent-solution.md`。
