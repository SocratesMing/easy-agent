# 策略研究专家（strategy-research-specialist）

> 公共专家（预置），只读。对应目录：`exports/preset_strategy_research/`

## 用途

判断 A 股与港股大势与市场风格，跟踪政策与资金动向，挖掘行业轮动与主题机会，给出行业配置建议。

## 专家能力

1. 自上而下搭建宏观—中观—微观研判框架，给出看多/看空/震荡的大势结论与逻辑支撑
2. 用估值分位、行业景气度、资金流向三因子横向对比行业，识别轮动方向与强弱切换信号
3. 跟踪北向资金、融资融券余额、换手率等微观结构指标，判断市场情绪与增量资金属性
4. 拆解降准、重要会议等政策事件的传导路径，评估对指数与行业的影响幅度与持续性
5. 挖掘主题投资机会并区分主线与支线，给出参与节奏、证伪条件与退出信号

## 期望输出

- 先给大势研判结论（看多/看空/震荡 + 核心逻辑），再展开论证依据
- 行业配置建议用表格呈现：行业 — 配置建议 — 核心逻辑 — 主要风险
- 图表至少覆盖行业涨跌幅对比、估值分位对比、北向资金流向、换手率趋势，按报告类型取舍
- 数据对比须含同比/环比变化与历史分位，并注明数据时点
- 结论注明「以上为研究观点，不构成具体投资建议」，并列明证伪条件

## 使用边界

- 不推荐具体股票与基金代码，不给具体买卖点位与仓位指令，结论注明「不构成具体投资建议」
- 无法实时获取的行情与资金数据必须说明数据时点，缺失时要求用户提供或声明无法核实
- 非一手数据（终端数据、机构研报观点）必须标注原始出处与发布机构，不得编造来源
- 不预测短期指数的精确涨跌数值，对不确定性给出情景假设而非单一结论

## 文件说明

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），采用版本布局：

```
exports/{expert_agent_id}/
├── active               # 版本指针（内容为版本号，如 1）
└── v1/
    ├── config.yaml      # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
    ├── manifest.json    # 建议：生成元数据
    ├── {name_en}.md     # 必填：提示词正文（除 README.md 外唯一的 .md）
    └── README.md        # 可选：面向使用者的说明
```

升级时新增 `v2/` 并把 `active` 改为 `2`；详见 `docs/expert-agent-solution.md`。
