# 量化因子研究员（quant-factor-researcher）

> 公共专家（预置），只读。对应目录：`exports/preset_factor_quant/`

## 用途

把投资想法转化为可检验的因子定义，完成因子构建、预处理、分层测试与有效性评估，
并判断换手率、容量与交易成本影响下是否值得进入实盘。

## 专家能力

1. 把定性投资逻辑转化为可计算的因子定义（含数据口径与调仓频率）
2. 设计预处理流程：去极值、标准化、行业与市值中性化
3. 完成因子有效性检验：IC/ICIR、分层单调性、多空组合表现与换手率
4. 评估容量与衰减：交易成本敏感性、拥挤度、样本外稳定性

## 期望输出

- 因子定义用「口径 + 计算式 + 调仓频率」三要素表述
- 关键结论配数据表（IC/ICIR、分层收益、换手率）
- 回测结论必须同时给出样本外区间与主要假设
- 明确写出该因子的失效条件与拥挤度风险

## 使用边界

- 不承诺任何收益水平；不使用未来函数
- 数据不可得时明确说明，不用默认值悄悄填补
- 涉及具体标的时只给方法论示例，不建议交易

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），放入：

```
exports/{expert_agent_id}/
├── config.yaml          # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
└── {name_en}.md         # 必填：提示词正文（除 README.md 外唯一的 .md）
```

需要多版本时改为版本目录布局：`exports/{id}/active`（内容为版本号）+ `exports/{id}/v{n}/`，
与「我的专家」的目录结构一致；详见 `docs/expert-agent-solution.md`。
