## 环境验收边界

以上代码与自动化验收已完成。上线前仍必须在行内环境执行两项不能在行外伪造的验收：

1. 用行内真实 RAGFlow 地址、证书和鉴权回归《行内 api》契约；
2. 由业务责任人对 PDF、DOCX、XLSX/PPTX 代表性研报问题的答案和引用签字。

这两项属于行内环境/业务验收，不用行外模拟结果替代。

## 已发现的历史数据异常

对账发现 1 条历史文档同时存在 `LOCAL_WITHOUT_REMOTE` 和 `NAS_MISSING`。系统已生成可追踪异常记录，未自动删除或伪造恢复；应由管理员核对原始来源后决定从备份回填或销毁该映射。2026-09-09 全面回归后再次确认，除这 2 条已知历史异常外没有新增未解决对账问题。
