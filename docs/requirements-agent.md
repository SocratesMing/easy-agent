## 1. 概述

### 1.1 背景

Easy Agent 是一个面向企业与个人用户的 AI Agent Web 应用。传统 Chatbot 只能
「一问一答」，无法真正完成工作：不能读写文件、不能执行命令、不能跨会话记住
用户偏好、也不会在危险操作前停下来请示。

本系统基于 LangChain DeepAgents 框架，为大模型配备工具、工作区、记忆与安全
护栏，让它能**自主完成多步任务**，同时把危险动作和越界访问置于用户确认与
系统约束之下。

### 1.2 目标用户

| 用户角色 | 核心诉求 |
| --- | --- |
| 普通用户 | 用自然语言完成文档生成、资料整理、数据分析、信息检索等任务 |
| 开发/运维人员 | 通过对话或网页终端执行命令、排查问题、生成代码 |
| 金融/量化研究者 | 生成量化策略、处理行情数据、查阅研报 |
| 系统管理员 | 管理用户、模型、知识库，保障多用户数据隔离与审计合规 |

### 1.3 产品目标（成功标准）

| 编号 | 目标 | 可度量标准 |
| --- | --- | --- |
| G1 | 端到端完成多步任务 | 单次任务可自主执行 ≥ 20 步；复杂任务（文档生成/代码改写）无需逐步指导即可产出可用文件 |
| G2 | 过程可见可控 | 用户可实时看到「思考 → 工具调用 → 工具结果 → 结论」全过程 |
| G3 | 数据隔离可靠 | 跨用户、跨会话的工作区与记忆互不可见；越界访问被拒绝且有日志 |
| G4 | 危险操作可控 | 删除类等危险操作 100% 需人工确认或被直接拒绝 |
| G5 | 长会话可承载 | 超长对话自动压缩上下文，不因超窗口而失败 |

### 1.4 范围

**包含**：对话与任务执行、工具调用（文件/命令/搜索/MCP/技能）、工作区与文件
管理、记忆、定时任务、人工审批（HITL）、路径与沙箱隔离、审计日志、多模型接入。

**不包含**：模型训练与微调、模型推理服务的部署、企业权限中心（RBAC/SSO）
的对接细节、前端交互视觉规范（另见前端设计文档）。

## 2. 术语表

| 术语 | 含义 |
| --- | --- |
| Agent | 智能体，由「大模型 + 系统提示词 + 工具集 + 记忆 + 中间件」组成 |
| 会话（Session） | 一次独立的对话上下文，拥有独立消息历史与工作区 |
| 工作区（Workspace） | 会话绑定的文件目录，Agent 读写文件的默认位置 |
| 工具（Tool） | Agent 可自主调用的能力单元（读写文件、执行命令、搜索等） |
| Skill | 以 `SKILL.md` 描述的可复用技能包，按需加载 |
| MCP | Model Context Protocol，外部工具/数据源接入协议 |
| HITL | Human-in-the-Loop，人工审批中断机制 |
| 虚拟路径 | 面向模型/用户的抽象路径（如 `/workspace/`），与宿主机真实路径解耦 |
| 长期记忆 | 跨会话持久化的用户偏好与可复用经验 |

## 3. 功能需求

> 每条需求包含：**描述**、**验收标准（AC）**、**优先级**（P0 必须 / P1 重要 / P2 可选）。

### FR-1 对话与任务执行

**FR-1.1 多轮对话（P0）**

- 用户以自然语言发起请求，Agent 结合历史上下文给出回复。
- 会话消息历史持久化，刷新页面或重启服务后可恢复。
- **AC1**：同一会话连续多轮提问，Agent 能引用前文信息。
- **AC2**：重启服务后重新进入会话，历史消息完整可读。

**FR-1.2 多步自主执行（P0）**

- Agent 可自主规划并连续执行多步（思考 → 调工具 → 观察结果 → 继续），
  直至任务完成或达到步数上限。
- 步数上限可配置（当前默认 100）。
- **AC1**：单次请求中可触发多次工具调用且顺序合理。
- **AC2**：达到上限时停止执行并返回已完成部分与原因，不静默失败。

**FR-1.3 流式输出（P0）**

- 执行过程以流式事件实时推送，覆盖思考、工具调用、工具结果、正文、用量等。
- 事件类型至少包含：`start`、`thinking_start`、`thinking`、`thinking_end`、
  `tool_call`、`tool_result`、`content`、`content_end`、`todo_list`、
  `token_usage`、`approval_required`、`done`、`error`。
- **AC1**：首个可见内容在请求发出后数秒内到达（受模型首 token 时延约束）。
- **AC2**：客户端断线重连后可回放已产生的事件，不丢帧（弱网/刷新场景）。

**FR-1.4 上下文自动压缩（P0）**

- 当对话 token 接近模型上下文窗口时，自动摘要历史，保留最近关键上下文。
- 压缩阈值与保留比例可配置，且以「当前实际使用的模型」的窗口为基准。
- **AC1**：超长会话可持续对话，不因超出窗口报错。
- **AC2**：压缩后仍能回答依赖前文的问题（关键结论未丢失）。

**FR-1.5 会话管理（P0）**

- 支持新建、列出、切换、重命名、删除会话；支持置顶。
- 会话标题自动生成（取首条消息或首个文件名）。
- **AC1**：删除会话后其工作区与消息不再可访问。
- **AC2**：切换会话后上下文与工作区正确切换，互不串扰。

### FR-2 工具调用能力

**FR-2.1 内置工具（P0）**

Agent 至少具备以下内置能力，并可自主决定调用时机：

| 工具 | 用途 |
| --- | --- |
| 任务规划（todo） | 拆解并跟踪多步任务进度 |
| 文件读写/编辑 | 读取、写入、增量编辑、按模式检索文件 |
| 目录浏览/搜索 | 列目录、按 glob 匹配、正则检索内容 |
| 命令执行（execute） | 在工作区内执行 Shell 命令 |
| 子任务委派（task） | 将子任务交给子智能体并汇总结果 |

- **AC1**：各工具调用结果在界面以独立卡片展示（含耗时、成功/失败）。
- **AC2**：工具失败时 Agent 能读取错误并尝试替代方案，而非直接中断。

**FR-2.2 联网搜索（P1）**

- 由用户显式开启后（输入框开关），Agent 获得联网检索能力，回答时效性问题时
  先检索再作答，并给出可溯源的来源链接。
- 支持检索深度、主题（通用/新闻/财经）、结果条数、时间范围、域名过滤等参数。
- 未配置检索服务凭据时，入口置灰，且不向 Agent 注入该工具。
- **AC1**：开启后提问时效性问题，回复包含来源链接。
- **AC2**：未开启/未配置时，Agent 不产生联网检索行为。

**FR-2.3 技能（Skill）调用（P1）**

- 系统预置公共技能（如文档处理、数据分析、量化等），用户可从技能中心将公共技能
  加入个人技能，也可自定义技能。
- 对话中 Agent 根据任务自动识别并加载相关技能的说明文档后执行。
- **AC1**：加入技能后，同一请求下 Agent 能调用该技能完成对应任务。
- **AC2**：未加入的技能不会被误加载。

**FR-2.4 MCP 外部工具接入（P1）**

- 用户可在设置中配置 MCP 服务（增/删/启停），接入外部工具与数据源。
- 配置按用户隔离保存，改动后即时生效，无需重启服务。
- **AC1**：添加 MCP 服务并启用后，Agent 可调用其提供的工具。
- **AC2**：删除后 Agent 不再调用该服务。

**FR-2.5 文档生成与处理（P0）**

- Agent 可生成 docx、pdf、pptx、xlsx、图片与代码文件，并保存在会话工作区。
- 生成文件可在「资产」区与当前会话中查看、下载、在线预览。
- **AC1**：要求生成文档后，工作区出现对应文件且可正常打开。
- **AC2**：常见格式（docx/pdf/pptx/xlsx/图片/代码）支持在线预览。

### FR-3 工作区与文件管理

**FR-3.1 工作区隔离（P0）**

- 每个「用户 × 会话」拥有独立工作区目录，Agent 默认只能在此读写。
- 可通过配置将宿主机的指定目录映射为虚拟路径，供技能访问，映射前需做越权校验。
- **AC1**：用户 A 无法通过任何工具读取或写入用户 B 的工作区。
- **AC2**：可能导致越权的目录映射被拒绝，并记录告警日志。

**FR-3.2 文件上传与预览（P0）**

- 支持在对话中上传文件作为上下文，支持下载与在线预览。
- 预览覆盖文档、表格、演示、图片、代码等常见类型。
- **AC1**：上传后 Agent 能读取并使用文件内容。
- **AC2**：不可预览的类型给出明确提示而非报错崩溃。

### FR-4 记忆

**FR-4.1 会话记忆（P1）**

- 每次会话结束后，自动提炼本轮的可复用结论（决策与依据、错误根因、约定与路径、
  断点与待办），写入该会话的记忆文件，供后续轮次续接。
- 记忆超长时自动压缩，保留核心信息。
- **AC1**：同一会话第二轮开始，Agent 能利用上一轮沉淀的结论。

**FR-4.2 长期记忆（P1）**

- 跨会话沉淀用户偏好与可复用经验，后续会话自动加载。
- 明确不记录：寒暄、一次性过程、原始日志、临时状态、密钥/凭据等敏感信息。
- **AC1**：新建会话时，Agent 能体现此前累积的用户偏好。
- **AC2**：任何记忆文件中不出现 API Key、密码、Token 等敏感值。

### FR-5 定时任务

**FR-5.1 自然语言创建（P1）**

- 用户在对话中用自然语言描述调度意图（如「每天早上 8 点汇总新增文档」），
  Agent 自动解析并创建定时任务，返回任务 ID 与下次执行时间。
- 任务属性至少包含：名称、描述、cron 表达式、执行时发给 Agent 的指令。
- **AC1**：给定调度语句，成功创建任务且 cron 与语义一致。
- **AC2**：cron 表达式非法时给出可理解的纠正提示。

**FR-5.2 调度与执行（P1）**

- 任务按 cron 自动触发执行；支持查看执行记录、立即执行、暂停/启用、删除。
- 后台执行不需要人工审批；执行结果与状态可查。
- **AC1**：到点后任务自动执行并生成执行记录。
- **AC2**：暂停/删除后不再触发。

**FR-5.3 多实例互斥（P1）**

- 多实例（多 pod / 多 worker）部署时，同一任务同一时刻只被一个实例执行。
- **AC1**：多实例并发触发同一 cron，仅一条执行成功，其余记录为「跳过（锁）」。

**FR-5.4 执行审计（P1）**

- 记录任务全生命周期事件（创建、重载、触发、跳过、成功、失败、取消等），
  落盘为结构化日志，便于追溯。
- **AC1**：任一任务的每次执行均可在审计日志中查到对应记录。

### FR-6 人工审批（HITL）

**FR-6.1 危险操作审批（P0）**

- 涉及文件删除等危险操作时，执行前暂停并请求用户确认，展示待操作对象。
- 用户可选择「批准」或「拒绝」；拒绝后 Agent 需调整方案，不得原样重试。
- **AC1**：删除文件命令触发审批弹窗并展示目标路径。
- **AC2**：未获批准前命令不真正执行；批准后才继续。

**FR-6.2 高危操作直接拒绝（P0）**

- 目录删除（`rm -r`、`rmdir`、`find -delete` 等）、删除受保护目录等，
  直接拒绝执行并返回原因，不进入审批流程。
- **AC1**：目录删除命令被拒绝且返回明确提示，工作区结构未被破坏。

### FR-7 安全与隔离

**FR-7.1 路径翻译（P0）**

- 面向模型与用户暴露虚拟路径，宿主机真实路径不外泄；命令输出中的真实路径需
  反向翻译为虚拟路径。
- **AC1**：Agent 输出（`pwd`、错误堆栈等）中不含宿主机绝对路径。

**FR-7.2 命令执行沙箱（P0，仅 Linux）**

- Shell 命令在隔离环境中执行，仅能访问工作区/技能/授权目录（读写）与系统目录
  （只读），其余宿主机路径不可见。
- 分级降级：优先完整容器隔离（bubblewrap）→ 非特权文件系统隔离（Landlock，
  需内核 ≥ 5.13）→ 均不可用时**拒绝执行**（fail-closed）。
- 非 Linux 平台无等效机制时拒绝执行命令。
- **AC1**：沙箱内命令无法读取工作区之外的宿主目录（如应用配置、其他用户数据）。
- **AC2**：环境变量中的服务端密钥不传入沙箱命令。
- **AC3**：无法建立隔离时，命令被拒绝而非在宿主机裸跑。

**FR-7.3 敏感信息保护（P0）**

- 不向 Agent 暴露服务端密钥、数据库口令、JWT 密钥等；日志与回复中不出现敏感值。
- **AC1**：Agent 无法通过环境变量/命令读取到服务端密钥。
- **AC2**：引用报错时敏感值已脱敏。

### FR-8 鉴权与多用户

**FR-8.1 身份认证（P0）**

- 用户注册/登录后获得访问凭据；除登录与健康检查外，所有接口需鉴权。
- 支持登录态失效与空闲超时（可配置）。
- **AC1**：未携带凭据访问受保护接口被拒绝（401）。
- **AC2**：凭据失效后需重新登录。

**FR-8.2 数据隔离（P0）**

- 会话、文件、任务、MCP 配置、记忆等均按用户隔离，操作前校验归属。
- **AC1**：用户 A 无法读取/修改用户 B 的任何会话、文件或任务（越权返回拒绝）。

### FR-9 多模型接入

**FR-9.1 多 Provider 支持（P0）**

- 支持 DeepSeek、Anthropic、OpenAI、火山方舟等，通过配置切换，无需改代码。
- 不同模型可分别配置上下文窗口；用量统计与压缩按当前模型口径计算。
- **AC1**：切换配置中的模型后，服务重启即用新模型，功能正常。
- **AC2**：流式思考内容（如 reasoning）能正确展示。

### FR-10 网页终端（P1）

**FR-10.1 Web Shell（P1）**

- 提供浏览器内的交互式终端，支持常用命令、命令历史。
- 复用同样的路径翻译与危险命令拦截策略。
- **AC1**：终端可执行基础命令并返回输出。
- **AC2**：危险命令按 HITL/拒绝策略处理。

### FR-11 可观测与审计（P1）

- 记录应用运行日志、错误日志与关键业务事件（登录、任务、工具调用等）。
- 结构化记录工具调用（名称、参数摘要、耗时、成功与否）与流式过程。
- **AC1**：出现问题时可通过日志定位到会话、步骤与工具调用。
- **AC2**：任务类操作有独立审计日志文件。

## 4. 非功能需求

| 类别 | 需求 | 验收标准 |
| --- | --- | --- |
| 性能 | 服务启动稳定可控 | 单实例冷启动（含数据库初始化）在 MySQL 正常网络下 < 5s；已初始化库再次启动显著更快 |
| 性能 | 流式体验 | 事件按产生顺序实时推送，前端不批量积压（代理不缓冲 SSE） |
| 可用性 | 降级不崩溃 | LLM/数据库/搜索/沙箱任一不可用时，服务可启动，相关能力给出明确提示 |
| 可靠 | 幂等初始化 | 建表/补列/建索引在并发多实例启动下安全 |
| 扩展 | 多副本部署 | 定时任务等互斥任务不重复执行（分布式锁） |
| 安全 | 最小权限 | 命令在受限沙箱执行；越界访问默认拒绝 |
| 可维护 | 配置化 | 环境差异通过 `config.yaml` + `.env.{AGENT_ENV}` 注入，不硬编码 |
| 兼容 | 数据库 | 支持 SQLite（默认）与 MySQL |
| 兼容 | 平台 | 后端跨平台可启动；沙箱隔离仅 Linux 提供，非 Linux 拒绝执行命令 |

## 5. 约束与假设

- Python ≥ 3.11，Node ≥ 20（前端构建）；数据库 SQLite/MySQL。
- 命令沙箱依赖 Linux 内核能力：`bubblewrap` 需可创建用户命名空间（容器中通常需
  `--cap-add SYS_ADMIN`）；Landlock 需内核 ≥ 5.13。二者皆不可用时 fail-closed。
- 模型需通过 OpenAI 或 Anthropic 兼容协议提供，且具备工具调用（function
  calling）能力。
- 用户消息与生成文件会存储在工作区/数据库，数据安全由部署方保障。

## 6. 边界

**始终做**

- 校验所有接口入参，鉴权后才访问数据
- 危险操作前确认或拒绝
- 越界路径访问拒绝并记录日志
- 敏感值脱敏，不写入日志/回复/记忆
- 变更表结构时同步升级 schema 版本

**需请示再做**

- 修改数据库表结构、新增外部依赖、调整安全策略（如关闭沙箱）
- 变更默认配置（模型、步数上限、上下文阈值）

**绝不做**

- 在无沙箱隔离的情况下执行 Agent 命令（除非显式配置为可信单用户环境）
- 让一个用户访问另一个用户的工作区/会话/任务
- 记录或输出密钥、Token、密码
- 在未获批准时执行被拒绝的危险操作
