## 1. C1：API 去 Database 门面（剩余域）

- 新增 5 个域门面：`UserRepository`、`FileRepository`、`ScheduledTaskRepository`、`ExpertRepository`、`ChatRepository`（薄委托既有 db 方法，不新增 SQL）。
- `api/auth.py`、`files.py`、`scheduled_tasks.py`、`expert.py`、`chat.py` 改为 `Depends(get_xxx_repository)`；目标文件无 `from ..db import Database`、无直接 `db.*` 业务调用。
- `get_database` 仅保留在 provider；直接调用路由函数的旧测试用 `_as_xxx_repository` 兼容。
- 仍存在的服务层边界：middleware 活跃时间、`verify_token_sso`、`get_task_workspace_name`、`chat_stream_generator`/`resume_stream_generator`、`session_uploads` 等仍接收 `repo.database`（仅传底层实例，不调用 Database 业务方法）。
- 未迁移 API：`settings.py`、`connectors.py`、`completion.py`、`prompts.py`、`terminal.py`、`skill_center.py`。
- 测试：新增 5 个 repository 测试 + C1 静态测试；目标套件 **199 passed**。

## 3. B1：生产 checkpointer / Store

- `checkpoints.py`：`validate_checkpoint_deployment()`；prod 且 worker/replica >1 时非 Postgres 启动失败；`EASY_ALLOW_LEGACY_CHECKPOINTER=1` 唯一逃生门；打开失败降级后仍非 Postgres 则关闭并抛错。
- `app.py`：`CheckpointDeploymentError` 直接 re-raise；新增 `start_store_backend()`/`shutdown_store()`。
- `stores.py`：`EASY_STORE_BACKEND=auto|postgres|sql`；auto 在 PG URI 且官方 `langgraph.store.postgres` 可用时用官方 `AsyncPostgresStore`，否则 MySQL `SqlStore`；失败回退不阻断。
- `deploy/k8s/agent-deployment.yaml`：注入 `EASY_CHECKPOINT_POSTGRES_URI`（Secret）、`EASY_REPLICA_COUNT=2`、checkpoint/store 开关与逃生门默认 0。
- 测试：`test_checkpoint_deployment.py`、`test_store_backend.py` 等，**70 passed**。
- 未做：`SqlStore`→官方 Store 数据迁移、pgvector 向量索引、Store prod fail-fast。
- 风险：K8s `EASY_REPLICA_COUNT` 需与 `spec.replicas` 同步；官方 `setup()` 首次需 DDL 权限；MySQL 无 PG 时仍用自研 saver。

## 5. D3：MCP session 复用

- 新增 `services/mcp_sessions.py`：按 `(scope, server, connection JSON)` 的 owner-task session 注册表；per-key 锁、idle TTL、连接异常重建一次、ToolException/超时不重试、scope/invalidate/全量关闭；统计。
- `mcp.py:_load_server_tools` 优先 `client.session` + `load_mcp_tools(session=...)`，官方无 session API 时退回 stateless。
- app shutdown 已接入 `await aclose_mcp_sessions()`。
- 测试：新增 11 项；MCP/连接器相关 **91 passed**。
- 限制：session key 不含 username（全局连接配置跨用户共享）；传输异常重试一次存在“已执行但响应丢失”至多一次语义；工具列表为首次快照。

## 6. D2：编译图复用

- 新增 `agent_graph_cache.py`：`SessionContext`、进程内 LRU `GraphCache`（`EASY_AGENT_GRAPH_CACHE_SIZE`，默认 32）、缓存键（model/tools/system_prompt/middleware/HITL/subagents/skills/permissions/memory/summarization/config/checkpointer/store）、`contextualize_tools()`。
- `agent.py`：`_create_agent` 改为“算键→查缓存→未命中才编译”；`create_deep_agent(backend=callable, context_schema=SessionContext)`（官方公开参数）；`astream(..., context=...)`；backend 按 context 解析 workspace/记忆/技能/外部目录；subagent/LoggingMiddleware 去 session_id。
- `agent_manager`：`init_agent_config` 清图缓存、`invalidate_user_agents` 清用户图；per-session EasyAgent 缓存保留。
- `orchestrator.pump_stream` 传 context；无 context 保持旧调用形态。
- 测试：新增 `test_graph_cache.py` 13 项、`test_agent_manager_graph_cache.py` 4 项、`test_stream_context_passing.py` 2 项；相关套件 **300 passed**（含 HITL/记忆/checkpoint/MCP/技能回归）。
- 复用条件：同用户/机构、同模型、同工具集、同系统/专家提示词、同技能集合、同 HITL/摘要配置、官方全局 saver、模型请求头不含 `{session_id}`。
- 明确降级（不缓存）：`opencode` provider 的 `x-opencode-session: "{session_id}"`、legacy per-session checkpointer、`EASY_AGENT_GRAPH_CACHE=0`。
- 风险：仅进程内（多 worker 各一份）；deepagents 0.6.8 的 callable backend 在 0.7 将移除；共享图日志前缀改为通用 `agent`；工具元数据复制采用 `object.__setattr__` 兼容旧测试。
