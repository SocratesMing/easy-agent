# 指令菜单与手动压缩验证

日期：2026-11-06。设计：[指令菜单与手动压缩](../design/指令菜单于手动压缩设计.md)。

## 已实现

- Vue 2、Vue 3 的 `/` 菜单将“指令”和“技能”按独立标题纵向分组，指令组提供“压缩 compact”，支持 `/com`、`/压缩`、鼠标、方向键与 Enter，并保护输入法组词；技能接口失败不影响指令。
- 执行只移除当前 slash 查询，保留其他草稿、技能 token、附件；不发送普通聊天消息。同会话主聊天和侧栏共用操作状态，生成、压缩、待审批或不支持模式时禁用。
- `POST /agent/sessions/{id}/context/compact` 接收 `model`、`request_id`；`GET /agent/sessions/{id}/context` 查询状态和结果。沿用 JWT 和会话归属校验。详情、历史接口也投影独立压缩记录。
- 租约与聊天共用，压缩采用每次操作独立 owner、续约和提交围栏；提交时验证未过期、未取消且 owner 未变化。条件释放不会清除接管者租约，runtime 部分更新不会覆盖其他字段。
- 使用真实编译图与公开 `aupdate_state`，保存摘要事件和独立 `context_compactions` 字段。原始 DB 聊天记录不变；checkpoint 保留原始消息，下一次模型调用应用摘要事件。
- 复用历史对齐逻辑的 dry-run，覆盖水合、补齐轮次、半截回复、历史不匹配和旧消息稳定 ID；先准备摘要、归档，再提交。自动压缩关闭时，手动操作仍使用正常 keep 和输入预算。
- 成功与跳过记录持久化并按请求 ID 去重；失败即时状态在当前页面保留。断线时保留请求 ID 和位置，查询权威结果后恢复，刷新不会自动发起第二次压缩。
- 占用环显示明确标注的上下文估算，累计供应商 input/output usage 保留；下一轮实际 usage 使用原统计路径。

## 支持范围与明确边界

- 已验证依赖为 **DeepAgents 0.7.28 / LangGraph 1.2.16**；私有摘要方法集中于 `agent/manual_compaction.py`，其他版本拒绝摘要操作，升级需重新验证。
- 支持单实例、单 worker、官方持久 SQLite saver 且 `agent.session_thread=true`；实际图 saver 必须与权威 saver 一致。业务库为 SQLite 时，checkpoint 必须是另一个数据库文件，避免提交围栏锁与 saver 写入死锁。
- legacy 内存回退、关闭 session thread、多 worker / 多副本均拒绝压缩。部署须如实设置现有 worker/replica 环境配置；本次未新增共享 checkpoint 或跨 Pod 路由支持。
- 服务端摘要超时 120 秒、客户端请求超时 130 秒；断线不等于回滚。请求 ID 是会话内幂等键，同一 ID 返回原结果，即使重试时 model 改变也不会重做；重新操作应使用新 ID。
- 归档成功后 checkpoint 提交前失败，允许留下孤立归档文件，失败路径不自动删除，随工作区目录清理。失败提示不写入普通聊天记录，也不作为成功 checkpoint 记录持久化。
- token 数为有效上下文加基础系统提示的估算，不含动态提示和工具 schema，不保证每次短历史压缩都节省 token。
- 已对失败会话调用真实 DeepSeek 摘要并验证当前托管前端刷新恢复；Vue 3 浏览器交互仍以模拟 API 验证。未做跨机器故障或真实网络中断压测；模型错误、读写异常和断线结果恢复通过故障注入验证。
