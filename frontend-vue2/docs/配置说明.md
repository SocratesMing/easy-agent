# frontend-vue2 前端配置说明

> 适用目录：`frontend-vue2/`（Vue 2.6 + @vue/cli 5）
> 配置读取入口：`src/config.js`；运行期配置生成：`scripts/generate-runtime-config.sh`

## 1. 配置来源与优先级

前端配置有两个来源，**运行期覆盖构建期**：

| 优先级 | 来源 | 载体 | 何时生效 |
| --- | --- | --- | --- |
| 高 | 运行期（runtime-config） | `dist/runtime-config.js` 里的 `window.__RUNTIME_CONFIG__` | 启动脚本生成，容器/部署时可改，**无需重新构建** |
| 低 | 构建期 | `.env` / `.env.<AGENT_ENV>`（Vue CLI 的 `VUE_APP_*`） | `npm run build` 时固化进 bundle |

`src/config.js` 按顺序取值：`window.__RUNTIME_CONFIG__` → `process.env.VUE_APP_*` → 默认值。

## 2. 运行期配置生成

`npm run build` 和 `npm run serve` 都会执行 `scripts/generate-runtime-config.sh`，
它根据**启动时的环境变量**写出 `dist/runtime-config.js`：

```js
window.__RUNTIME_CONFIG__ = {
  AGENT_ENV: "prod",
  API_BASE_URL: "/",
  APP_TITLE: "Easy Agent",
  APP_WELCOME_TITLE: "",
  LOGIN_PAGE_ENABLED: true,
  ENV_CONFIG: { dev: {...}, test: {...}, prod: {...} }
};
```

脚本可识别的环境变量：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `API_BASE_URL` | `/` | 后端地址。默认相对路径（同源访问、无需 CORS）；跨域分离部署时才显式指定 |
| `AGENT_ENV` | `prod` | 环境标识，决定加载哪份 `ENV_CONFIG` |
| `APP_TITLE` | `Easy Agent` | 应用名称（浏览器标题/登录页） |
| `APP_WELCOME_TITLE` | 构建期值 | 首页欢迎语 |
| `LOGIN_PAGE_ENABLED` | `true` | **登录页开关**，详见第 3 节 |
| `DIST_DIR` | `dist` | 输出目录 |

> 布尔解析：`false` / `0` / `no` / `off`（忽略大小写）视为关闭，其余视为开启。

## 3. 登录页开关 `LOGIN_PAGE_ENABLED`

用途：控制「未登录时是否显示登录页」。生产环境通常**关闭**，改用后台的
「按用户名 + 工号免密注册并登录」能力。

| 取值 | 行为 |
| --- | --- |
| `true`（默认） | 未登录时显示 `Welcome` 登录 / 注册页，与原有行为一致 |
| `false` | **不显示登录页**：启动时先尝试 URL 免密直登；已有有效登录态则直接进入；两者都不满足时显示「未授权访问」提示页 |

### 关闭时的登录方式：URL 免密直登

访问链接携带参数即可自动注册并登录：

```
https://<前端地址>/?username=<用户名>&user_id=<工号>
```

- 前端调用后端 `POST /agent/auth/login-passwordless`，请求体 `{ username, user_id }`。
- 用户已存在：直接登录；不存在：自动注册后登录。
- 登录成功后前端会清除地址栏中的参数，避免留在历史记录 / 访问日志里。
- 注意：`user_id` 全局唯一。若传入的 `user_id` 已被其他用户占用，后端返回 400，
  前端回落为「未授权访问」提示。

> 「工号」在这里作为 `user_id` 传入（当前后端免密接口的字段名就是 `user_id`，
> 不是 `employee_id`）。若后端后续改为接收 `employee_id`，只需调整 `src/config.js`
> 之外的前端参数名与 `handlePasswordlessUrlLogin` 的读取键。

## 4. 使用示例

开发（默认开启登录页）：

```bash
cd frontend-vue2
npm run dev
```

生产 / 部署（关闭登录页）：

```bash
# 方式一：构建/托管时用环境变量注入运行期配置
LOGIN_PAGE_ENABLED=false \
API_BASE_URL=http://easy-agent-backend:8000 \
npm run build      # 生成 dist/ 与 dist/runtime-config.js
```

```bash
# 方式二：已构建好的 dist，重新生成运行期配置（无需重新构建）
cd frontend-vue2
LOGIN_PAGE_ENABLED=false API_BASE_URL=/ DIST_DIR=dist \
  sh scripts/generate-runtime-config.sh
```

容器化部署：把 `LOGIN_PAGE_ENABLED=false` 作为容器环境变量传入，由启动脚本写入
`runtime-config.js` 即可。

## 5. 各环境 `.env.<mode>`

`ENV_CONFIG` 表由脚本读取各 `.env.<mode>` 的 `VUE_APP_API_BASE_URL` 生成，仅作
各环境地址参考；实际生效地址仍以运行期 `API_BASE_URL` 为准。当前约定：

- `AGENT_ENV=dev` → 开发地址
- `AGENT_ENV=test` → 测试地址
- `AGENT_ENV=prod` → 生产地址

## 6. 说明

- 本说明针对 `frontend-vue2/`。Vue 3 版 `frontend/` 暂未支持 `LOGIN_PAGE_ENABLED`，
  其运行期配置生成脚本为 `frontend/scripts/generate-runtime-config.sh`。
- 登录页开关只影响「是否展示登录页」，不改变登录接口本身；后端接口与鉴权逻辑不变。
