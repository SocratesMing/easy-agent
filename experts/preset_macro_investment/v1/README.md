# 宏观投研专家（macro-investment-researcher）

> 公共专家（预置），只读。对应目录：`exports/preset_macro_investment/`

## 用途

解读宏观指标预测（CPI 优先）、央行议息会议结论与机构观点，三路交叉验证后输出约一页的可追溯宏观简报。

## 依赖技能与数据服务

必须经过 `macro-research`（宏观研究 / 宏观投研）技能，技能通过宿主已载入的 MCP 服务取数，覆盖三类能力：

| 能力别名 | 最低要求 | 说明 |
| --- | --- | --- |
| 指标预测 | 优先 CPI | 用户指定其他指标可用时补充；取得预测内容、目标期、数值与单位 |
| 议息解读 | 最近可用的已公布会议 | 包含政策动作、倾向或主要理由 |
| 机构观点 | 至少一家可识别机构 | 宏观或政策观点；条件允许时比较 2–3 家 |

技能只查询已有研究结果，不启动模型训练、不生成新报告，也不扩展到资产走势与交易策略。

## 专家能力

1. 按「指标预测 / 议息解读 / 机构观点」三路取证，每份资料登记服务名、工具名、记录定位与查询时间
2. 解读技能给出的指标预测：目标期、数值、单位与口径逐项核对，不推断技能未给出的含义
3. 解读最近可用的已公布议息会议结论，区分政策动作、倾向与主要理由
4. 比较 2–3 家机构观点，区分一致与分歧并说明分歧来源
5. 做三路交叉判断：预测信号、政策关注点、机构共识如何对应
6. 分辨预测目标期、会议日期、研报日期、生成时间与查询时间，避免时点混用

## 期望输出

- 结构、字段与顺序以技能简报模板为准：取证截止时间与三路验收结果、三路资料摘要、综合判断、一致与分歧、关键限制、最多三项待核对信息
- 正文约一页，默认中文 Markdown 并沿用用户简繁体；调用与来源记录可作附表
- 每个关键结论附来源编号（`S1`、`S2`…），来源清单写清服务名、工具全名、脱敏参数、记录定位、查询时间与资料日期
- 专家只补三处：结论摘要、证据一致性与矛盾说明、关键限制与待核对信息

## 使用边界

- 只查询已有研究结果，不启动模型训练、不生成新报告
- 不扩展到资产走势与交易策略，范围外问题直接说明并建议改用对应专家
- 不编造指标数值、预测值、政策判断、机构观点与来源，未取到就写「未取得」
- 三路全部失败或不可用时仍交付简报并如实标注缺口，不生成看似已验证的结论
- 不从单个调优中的预测值直接推断衰退，不强行统一互相矛盾的来源
- 不推荐具体金融产品与标的，结论注明「不构成具体投资建议」

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `config.yaml` | 卡片/详情页展示字段与生成元数据（分类标签、技能标签、示例问题等） |
| `manifest.json` | 生成元数据（版本、提示词文件名、生成时间等） |
| `macro-investment-researcher.md` | 专家提示词正文（召唤时注入系统提示词末尾） |

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），采用版本布局：

```
exports/{expert_agent_id}/
├── active               # 版本指针（内容为版本号，如 1）
└── v1/
    ├── config.yaml      # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
    ├── manifest.json    # 建议：生成元数据
    ├── {name_en}.md     # 必填：提示词正文（除 README.md 外唯一的 .md）
    └── README.md        # 可选：面向使用者的说明
```

升级时新增 `v2/` 并把 `active` 改为 `2`；详见 `docs/expert-agent-solution.md`。
