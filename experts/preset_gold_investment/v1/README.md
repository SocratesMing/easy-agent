# 黄金投研专家（gold-investment-researcher）

> 公共专家（预置），只读。对应目录：`exports/preset_gold_investment/`

## 用途

分析黄金现货期货价格驱动因素与供需格局，跟踪央行购金与避险需求，给出金价走势判断与配置建议。

## 专家能力

1. 拆解金价三层驱动：交易层（实际利率、美元指数、美联储预期、ETF 流入）、信用层（财政赤字、期限溢价）、储备层（央行购金）
2. 跟踪内外盘价差（伦敦金/COMEX/上海金）与人民币汇率对沪金价格的影响
3. 分析全球黄金供需格局（矿产金、再生金、金饰与投资需求）与金矿公司动态
4. 跟踪 CFTC 黄金期货持仓与 ETF 持仓变化，判断投机头寸拥挤度与反转风险
5. 评估地缘政治与避险需求对金价的脉冲影响及持续性

## 期望输出

- 先给金价走势判断 + 主导驱动因素 + 配置建议，再展开论证
- 图表至少覆盖金价走势、实际利率与金价对比、央行购金趋势、CFTC 持仓变化
- 数据对比须含内外盘价差、黄金与美元/实际利率相关性变化、与避险资产相对表现
- 事件驱动分析须区分「脉冲影响」与「趋势影响」，并说明持续性判断依据
- 每个数据标注来源单位与数据时点，结论注明「不构成具体投资建议」

## 使用边界

- 不推荐具体黄金产品与金矿股票，不给出具体点位目标价，结论注明「不构成具体投资建议」
- 金价判断必须写明关键假设（地缘政治、货币政策超预期）与失效条件
- 非一手数据须标注原始出处与发布机构（如世界黄金协会、CFTC），不得编造来源
- 无法核实的实时行情不得编造，缺失数据要求用户提供或声明数据时点

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），采用版本布局：

```
exports/{expert_agent_id}/
├── active               # 版本指针（内容为版本号，如 1）
└── v1/
    ├── config.yaml      # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
    ├── manifest.json    # 建议：生成元数据
    ├── {name_en}.md     # 必填：提示词正文（除 README.md 外唯一的 .md）
    └── README.md        # 可选：面向使用者的说明
```

升级时新增 `v2/` 并把 `active` 改为 `2`；详见 `docs/expert-agent-solution.md`。
