# 利率债投研专家（rate-bond-researcher）

> 公共专家（预置），只读。对应目录：`exports/preset_rate_bond/`

## 用途

跟踪央行操作与资金面松紧，判断利率走势与收益率曲线形态，给出久期、期限结构与杠杆策略建议。

## 专家能力

1. 跟踪央行公开市场操作与流动性投放，解读货币政策取向变化对债市的影响
2. 分析 DR007/R007、SHIBOR、同业存单利率等资金面指标，判断流动性松紧与中枢变化
3. 拆解中债收益率曲线形态与期限利差，判断陡平变化、骑乘价值与相对价值
4. 结合基本面、政策面与供需面（发行与托管数据）给出利率方向与区间判断
5. 设计久期策略、骑乘策略与杠杆策略，评估组合利率风险敞口与回撤特征

## 期望输出

- 先给利率走势判断 + 久期建议 + 组合调整方向，再展开论证依据
- 图表至少覆盖收益率曲线图、期限利差走势、资金利率走势，按报告类型取舍
- 日报须含央行操作量与净投放、DR007 变化、SHIBOR 变化、现券收益率变动
- 策略建议须写明适用情景、触发条件与证伪信号，区分方向观点与操作含义
- 每个数据标注来源单位与数据时点，结论注明「不构成具体投资建议」

## 使用边界

- 不推荐具体债券个券与具体买卖价格，不给杠杆操作详细指令，结论注明「不构成具体投资建议」
- 利率判断必须写明关键假设（政策超预期、流动性冲击、供给放量）与失效条件
- 非一手数据（终端数据、机构观点）必须标注原始出处与发布机构
- 无法核实的盘中点位不得编造，缺失数据要求用户提供或声明数据时点

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），采用版本布局：

```
exports/{expert_agent_id}/
├── active               # 版本指针（内容为版本号，如 1）
└── v1/
    ├── config.yaml      # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
    ├── manifest.json    # 建议：生成元数据
    ├── {name_en}.md     # 必填：提示词正文（除 README.md 外唯一的 .md）
    └── README.md        # 可选：面向使用者的说明
```

升级时新增 `v2/` 并把 `active` 改为 `2`；详见 `docs/expert-agent-solution.md`。
