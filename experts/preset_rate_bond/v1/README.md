# 利率债投研专家（rate-bond-researcher）

> 公共专家（预置），只读。对应目录：`exports/preset_rate_bond/`

## 用途

按研究类型经 `dc-research`（利率债投研）技能取行情、短端与长端信号及机构行为数据，交叉验证后输出可追溯的利率债投研策略报告。

## 依赖技能与数据服务

必须经过 `dc-research`（中文名「利率债投研」「利率债投研策略」，技能文档标题为「债券研究」）技能，技能通过宿主已载入的 MCP 服务取数，覆盖四个服务：

| 服务 | 能力 | 首次查询 |
| --- | --- | --- |
| 债券 xBond 行情问数 | 债券行情与成交深度 | `describe_bond_schema` |
| 1 年期国债模型 | 短端收益率信号 | `describe_treasury_1y_schema` |
| 10 年期国债趋势判断 | 长端收益率信号 | `describe_rates_timing_schema` |
| iData 债券分析 | 机构资金流与借贷行为 | 按运行时 schema |

**不同策略类型走不同分支**：先按技能的需求路由确定本次涉及的领域，只读涉及的参考文档，不一次性全量取数。端点与工具数以运行时 schema 为准。

## 专家能力

1. 通过债券行情服务取收益率与成交深度，区分「有成交的价」与「估值价」并说明流动性差异
2. 解读 1 年期国债模型的目标期、方向与概率，明确它只适用于该模型指定的目标
3. 解读长端趋势判断的窗口与方向；判断曲线形态时要求两端信号同时支持
4. 使用机构资金流与借贷余额作为行为证据，不单独据此推断杠杆率或做空目的
5. 行情、短端、长端、机构行为互相矛盾时并列呈现并给出可能原因
6. 分辨资料观测期、行情时间戳、信号日、资金流日期与取数时间，按频率差异使用证据
7. 为每个来源建 `S1`、`S2` 编号，关键结论挂来源编号

## 期望输出

- 结构、字段与顺序以技能的 `assets/report-template.md` 为准：资讯 / 结论 / 数据 / 分析 / 策略 / 风险与来源
- 策略表写清债券品种与期限、方向（收益率方向与债券价格方向分列）、持有期限、支持来源、反向证据与触发 / 失效条件
- 结论可信度用「高 / 中 / 低 / 不足以判断」并给出理由：资料新鲜度、覆盖数、模型证据、来源分歧
- 情景概率只在有模型或统计依据时填写；1Y 模型概率仅适用于其指定目标，不等于整份情景概率
- 每个关键结论附来源编号，来源清单写清工具、实际参数、资料日期、查询时间与记录 ID

## 使用边界

- 不编造收益率、点位、成交笔数、资金流与模型概率，未取到就写「未取得」
- 授权、未载入、资料表缺失等问题不循环重试，不无限轮询、不触发生成或训练
- 返回笔数等于请求上限时视为「可能截断」，需核对可用期间与返回数量
- 服务全部不可用时只交付资料缺口与取数计划，不生成看似已验证的结论
- 不推荐具体个券与买卖价格，不给杠杆操作详细指令，结论注明「不构成具体投资建议」
- 只做利率债及其资金面、机构行为研究，信用债、可转债与其他市场问题直接说明并建议改用对应专家

## 文件说明

## 如何新增 / 修改公共专家

在 `exports/` 下新建一个目录（目录名建议与 `expert_agent_id` 一致），采用版本布局：

```
exports/{expert_agent_id}/
├── active               # 版本指针（内容为版本号，如 1）
└── v1/
    ├── config.yaml      # 必填：name_cn / tag_id / description / skills_names / features_prompt ...
    ├── manifest.json    # 建议：生成元数据
    ├── {name_en}.md     # 必填：提示词正文（除 README.md 外唯一的 .md）
    └── README.md        # 可选：面向使用者的说明
```

升级时新增 `v2/` 并把 `active` 改为 `2`；详见 `docs/expert-agent-solution.md`。
